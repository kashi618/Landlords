# 斗地主 - Fight the Landlord
## About the Project
When playing the game 斗地主 (Fight the Landlord), keeping track of each player's score is quite a chore, especially after playing many rounds (or when drinking is involved). Human errors from mental math, and scattered paper notes keeping track of scores, are often unreliable and quickly becomes chaotic. 
This project is a lightweight CLI too written exclusively in C, that automatically calculates and tracks scores, storing them in simple .txt files.

## Built With
- C

## Roadmap
- Title screen and main menu
- Reading and writing from file
- New player creation
- Game score calculation logic
- View score table
- Option for 2 deck game, with 4+ players
